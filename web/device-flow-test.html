GitHub Device Flow - Test Page

Vanilla HTML/JS client for the dash-xd/github-device-auth router. Runs the full device flow over the /auth/github/device?full&cache SSE endpoint, waits for the resulting token to land in the tenant-scoped GCS cache bucket (see internal/tenantstorage), then calls /auth/github/token to read it back.

Deployment

EventSource can't send POST bodies/headers, and the SSE endpoint here is a POST route, so this page streams the response with fetch() and parses event:/data: frames itself instead - see startDeviceFlow() below.
